# spacehop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port noswoosh 1.7.7 into an owned, line-audited, network-free instant Space switcher for macOS 27.

**Architecture:** A few Swift files compiled with plain `swiftc` (no package manager, no dependencies) into one binary `spacehop`, run as a user LaunchAgent. Every build signs with a local self-signed identity and runs a binary scanner that fails on networking, process-launch, or dynamic-loading code.

**Tech Stack:** Swift 6.4 (`swiftc`), AppKit, Carbon (hotkeys), CoreGraphics event taps, private SkyLight, bash, `nm`/`otool`/`strings`, `codesign`, `launchd`.

**Spec:** `docs/superpowers/specs/2026-11-18-spacehop-design.md`

## Global Constraints

- Target: macOS 27.2.1, arm64. Build: `swiftc -O -F /System/Library/PrivateFrameworks -framework SkyLight`.
- No network code, no updater, no process launching, no `dlopen`/`dlsym`, no environment-variable switches, no third-party dependencies, no GitHub Actions.
- Keyboard: only Carbon `RegisterEventHotKey` for Ctrl+Left/Right. No keyboard event tap.
- Event tap mask: event types 29 and 30 only.
- Names: binary `spacehop`; LaunchAgent label `com.remixtedi.spacehop`; event tag `0x5348_4F50` ('SHOP'); hotkey signature `0x5348_4F50`.
- Paths: binary `~/.local/bin/spacehop`; log `~/Library/Logs/spacehop.log`; keychain `~/Library/Keychains/spacehop-signing.keychain-db`; secret `~/.config/spacehop/signing-keychain-password` (mode 600); signing identity CN `spacehop local signing`.
- Every ported section gets an `AUDIT.md` entry in the spec's format, in the same commit.
- Commits: owner identity (Giorgi Tediashvili <remixtedi@gmail.com>), no AI attribution, nothing pushed until owner approves at the end.
- Deviation from spec, builder's call: several source files instead of one `spacehop.swift`, so pure logic can be compiled into a test binary. Still one output binary.

## Review Focus

1. **Natural scrolling off** — Ctrl+Right must still move right. Pinned by `test_postedSign_naturalOff` (Task 3).
2. **Rapid double press at the second-to-last Space** — second press must land on the last Space, a third must do nothing (no bounce). Pinned by `test_clamp_and_prediction` (Task 3).
3. **Accessibility not yet granted** — daemon must log, not crash, and exit once trusted so launchd restarts it. Manual check in Task 6.
4. **Scanner false negative** — a binary that uses `URLSession` or `Process` must fail the build. Pinned by `tests/check-binary-test.sh` (Task 1).
5. **Teardown after a crashed/partial setup** — `spacehop teardown` must re-enable hotkeys 79/81 even if never disabled. Pinned by manual check in Task 5.
